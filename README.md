# DOLLZ GLAM STUDIO 💋

A Y2K Fashion Doll Makeover Browser Game

## 1. Game Overview

Dollz Glam Studio is an interactive fashion and makeover browser game inspired by the Y2K and Bratz fashion aesthetic.

Players can create their own fashionable doll from scratch by customizing her appearance, applying makeup, choosing hairstyles, selecting outfits, and adding accessories.

The game will feature a glamorous early-2000s aesthetic using hot pink, purple, silver, and black.

The game will be developed using HTML, CSS, and JavaScript and published for free using GitHub Pages.

## 2. Main Goal

The main goal is to create a unique and fashionable doll by completing four makeover stages:

1. Create your doll.
2. Apply makeup.
3. Choose a hairstyle.
4. Select outfits and accessories.

After completing the makeover, players can showcase their doll in a photoshoot and fashion runway.

## 3. Player Controls

The game will use simple mouse and touch controls.

- Click buttons to select customization options.
- Click colors to change makeup and hair.
- Click categories to switch between customization stages.
- Use the next and back buttons to navigate.
- Use the reset button to start again.
- Use the finish button to complete the makeover.

## 4. Gameplay and Customization

### Stage 1: Create Your Doll

Players can customize:

- Different skin tones.
- Eye colors.
- Eye styles.
- Facial features.

### Stage 2: Makeup Studio

Players can apply different makeup products.

Available options:

- 8 lipstick colors.
- 8 eyeshadow colors.
- 5 blush colors.
- Eyeliner options.
- Mascara options.

The makeup must visibly change the doll's appearance when selected.

### Stage 3: Hair Salon

Players can choose from 8 hairstyles:

1. Straight hair.
2. Curly hair.
3. Wavy hair.
4. High ponytail.
5. Braids.
6. Short bob.
7. Space buns.
8. Pigtails.

Players can also select different hair colors.

### Stage 4: Fashion Studio

Players can customize their doll using Y2K-inspired fashion items:

- Crop tops.
- Mini skirts.
- Flared jeans.
- Trendy jackets.
- Platform shoes.
- Handbags.
- Sunglasses.
- Earrings.
- Necklaces.

Players can mix and match clothing and accessories.

## 5. Final Showcase

Once the doll's makeover is complete, three additional features become available.

Fashion Photoshoot

- Display the completed doll.
- Choose a background.
- Allow players to save a screenshot of their creation.

Fashion Runway

- Display the doll on a fashion runway.
- Add simple animations and visual effects.

Final Style Rating

- Calculate a score out of 100.
- Display the final score.
- Show a congratulatory message.

## 6. Scoring System

Players earn points for completing each customization category.

| Category | Points |
| --- | --- |
| Doll creation | 20 |
| Makeup | 25 |
| Hairstyle | 15 |
| Fashion outfit | 25 |
| Accessories | 15 |
| Total | 100 |

The game will calculate and display the final score after the makeover is completed.

## 7. Win and Lose Conditions

Winning conditions:

- Complete all four customization stages.
- Finish the doll's makeover.
- Unlock the final showcase.
- Receive a final style rating.

Losing conditions:

There will be no losing condition because this is a creative dress-up game. Players can experiment with different styles and replay the game as many times as they want.

## 9. Technical Requirements

The game will be developed using:

- HTML5: Creates the structure of the game.
- CSS3: Controls the design, colors, layout, and animations.
- JavaScript: Handles customization, buttons, scoring, and gameplay.

The game must:

- Work as a static website.
- Require no backend or database.
- Require no Python server.
- Require no login or registration.
- Require no paid services.
- Require no secret API keys.
- Work without external frameworks.

All necessary files and artwork will be included in the project folder.

## 10. Publishing

The completed game will be published using GitHub Pages.

Players will be able to:

- Open the game through a shared website link.
- Play directly in their browser.
- Customize and save a screenshot of their doll.
- Play without downloading or installing anything.
